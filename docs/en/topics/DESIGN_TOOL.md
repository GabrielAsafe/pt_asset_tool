# Design Tool Guide

Use PT Asset Tool as the first-party Design Tool for physical asset discovery, contract/binding inspection, 3D validation, staged editing, and transactional publication.

## Recommended workflow

1. Configure client root.
2. Run Doctor/dependency diagnostics.
3. Reindex the catalog.
4. Find the asset in Catalog or Game Entities.
5. Distinguish structural, binding, visual, and roundtrip evidence.
6. Use only the capabilities exposed for that asset.
7. Keep edits in `pt_build` until a certified publication workflow is ready.
8. Run validation gates before release.
