# Asset Enrichment Guide

Asset Enrichment connects server definitions to client physical assets through typed bundles and evidence.

Use it to answer questions such as:

- Which visual package does this Monster/NPC definition resolve to?
- Does this Field have SPM/SPP/SPC metadata?
- Which client icon/model corresponds to an OpenItem/runtime code?
- Is a missing client/server path recoverable from a donor/reference root?
- Is a relationship CLOSED, PARTIAL, REVIEW, or BLOCKED?

Do not treat persistence tables, logs, security state, or operational databases as assets merely because they are under the server tree.
