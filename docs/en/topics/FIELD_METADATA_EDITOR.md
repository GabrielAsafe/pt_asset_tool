# Field Metadata Editor

Field authoring is split by metadata type:

- **SPM** — spawn actors/bosses/directives.
- **SPP** — canonical start-point records.
- **SPC** — canonical fixed-NPC records.

The semantic map catalog can resolve a map display name to the expected field/stage/spawn targets. Related mob/NPC selectors reduce manual entry of internal names.

These writers do not create or modify the client visual Stage geometry.
