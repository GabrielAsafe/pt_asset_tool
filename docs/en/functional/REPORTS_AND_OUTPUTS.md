# Reports and Outputs

Generated reports and staged outputs live under:

```text
app/pt_build/
```

Important families include:

- General Census;
- asset retention;
- effect runtime coverage/components;
- quarantine plans and transaction store;
- cooked texture evidence;
- texture enhancement runs;
- Legacy Management authoring staging/manifests;
- comparison exports;
- particle preview plans/renders;
- validation reports.

Reports are evidence snapshots. Commands that query an existing report do not necessarily rerun the analysis that produced it. Regenerate the authoritative analysis after changing the physical client/server tree.
