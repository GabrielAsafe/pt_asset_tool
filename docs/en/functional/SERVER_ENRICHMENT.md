# Server Enrichment

Server Enrichment is the read/analysis surface for Summit server content.

It provides:

- server-root configuration;
- source/reference/donor configuration;
- environment preflight;
- physical server inventory;
- General Census;
- recovery-plan and contract evidence;
- dependency graph;
- retention projection;
- handoff to Legacy Management when content needs editing.

Persistence/security/log state remains outside the asset graph unless explicitly modeled by a separate administration contract.
