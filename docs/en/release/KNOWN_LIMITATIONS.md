# Known Limitations

- English localization intentionally does not translate game display names stored in the semantic catalog.
- Raw historical evidence, source snippets, and legacy reference documents may remain in their original language.
- A translated UI label does not change a runtime identifier, path, code, or contract token.
- Localization does not add new delete authority; quarantine remains reversible and fail-closed.
- Legacy content formats that remain REVIEW/BLOCKED are not promoted by localization.
