# Release Notes — English Localization V2.10

V2.10 makes English the default application and operational-documentation language.

Highlights:

- English first-party UI labels, help text, toasts, and user-facing workflow messages.
- English operational documentation under `docs/en/`.
- Existing Portuguese documentation retained as historical/provenance material.
- Semantic catalog game display names remain unchanged source data.
- Internal IDs, runtime codes, paths, hashes, and evidence tokens are never translated.
- No change to retention/quarantine/delete authority.
- No change to authoring transaction safety.
